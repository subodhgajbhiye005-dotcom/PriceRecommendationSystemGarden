# Login & Registration Forms

## 🌐 **Access Your Forms:**

### **Standalone Login Form**
**URL:** http://localhost:3000/login
- Clean, modern login interface
- Email/password authentication
- Links to registration
- Demo credentials display

### **Standalone Registration Form**
**URL:** http://localhost:3000/register
- Complete user registration
- Password confirmation
- Optional location field
- Links back to login

### **Main Application (Protected)**
**URL:** http://localhost:3000
- Automatically redirects to login if not authenticated
- Full price recommendation system after login

1. Visit http://localhost:3000/login
2. Use demo credentials or register a new account
3. Get redirected to the main application
4. Use the price recommendation system
5. Logout and try different accounts

Both forms are fully functional and integrated with your existing authentication system!
