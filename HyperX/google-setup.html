🔐 Google OAuth Setup Guide

Follow these steps to enable Google login for your Price Recommendation System.

⚠️ Important: You need actual Google OAuth credentials to test Google login. The placeholder values in .env won't work.

Step 1: Create Google Cloud Project

Go to Google Cloud Console

  • Create a new project or select an existing one
  • Make sure billing is enabled (required for OAuth)

Step 2: Enable Google+ API

  • Go to "APIs & Services" > "Library"
  • Search for "Google+ API" and enable it

Step 3: Create OAuth Credentials

  • Go to "APIs & Services" > "Credentials"
  • Click "Create Credentials" > "OAuth 2.0 Client ID"
  • Choose "Web application" as application type
  • Add authorized redirect URIs: http://localhost:3000/auth/google/callback

Step 4: Update Environment Variables

Edit the .env file in your project root:

GOOGLE_CLIENT_ID=your-actual-client-id-here
GOOGLE_CLIENT_SECRET=your-actual-client-secret-here

Step 5: Test Google Login

  • Restart your server: node server.js
  • Go to http://localhost:3000/login
  • Click the "🔍 Google" button
  • You should be redirected to Google for authentication
✅ What's Working:
  • Google login button is functional
  • OAuth routes are configured
  • Database schema supports Google users
  • Passport.js integration is complete
🔧 Troubleshooting:
  • Make sure your redirect URI exactly matches: http://localhost:3000/auth/google/callback
  • Check that your domain is authorized in Google Cloud Console
  • Verify your Client ID and Secret are correct in .env
  • Restart the server after changing environment variables
